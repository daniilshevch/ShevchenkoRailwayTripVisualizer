# RailwayMapTest

Прототип: список станцій Укрзалізниці → маршрут поїзда по реальних коліях на карті OpenRailwayMap.

## Перший запуск

```
npm install
curl -L -o data/ukraine-latest.osm.pbf https://download.geofabrik.de/europe/ukraine-latest.osm.pbf
node --max-old-space-size=6144 import-osm.js     # кілька хвилин, створює data/ua-rail.json
node server.js                                   # відкрити http://localhost:3000
```

Без браузера: `node cli.js stations.json route.geojson`.

## Оновлення даних

OSM редагують постійно (нові колії, виправлення, перейменування). Щоб підтягнути свіжі дані, скачайте новий `.pbf` (Geofabrik оновлює його щодня) і запустіть `import-osm.js` ще раз. Кеш готових маршрутів прив'язаний до дати імпорту, тож після оновлення маршрути перебудуються.

## Формат stations.json

```json
{ "stations": ["Одеса-Головна", "Роздільна-1", "Львів"] }
```

Елемент може бути об'єктом із ручними координатами, якщо станцію не вдається знайти за назвою:
`{ "name": "Моя станція", "lat": 49.83, "lon": 24.0 }`.

## Як це працює

1. **Дані.** `import-osm.js` бере з повного OSM-екстракту України лише колії `railway=rail` без `service=*` (тобто без депо, тупиків і під'їзних) та всі станції й зупинні пункти. Це ті самі дані, які малює OpenRailwayMap.
2. **Станції.** Назва зіставляється з нормалізацією (`Роздільна I` = `Роздільна-1`, `Львів` → `Львів-Головний`, враховуються старі назви на зразок «Котовськ»). Серед однойменних станцій обирається найближча до попередньої станції маршруту.
3. **Маршрут.** Граф усієї мережі будується в пам'яті один раз при старті. Далі алгоритм Дейкстри, де станом є напрямлене ребро: так заборонені різкі розвороти на стрілках (> 110°), яких поїзд фізично не може зробити.
4. **Карта.** Leaflet + підкладка OSM + шари OpenRailwayMap (інфраструктура / швидкості / електрифікація).

Готові маршрути кешуються в `cache/routes/` за точним списком станцій.

## Обмеження прототипу

- Обирається найкоротший шлях, а не той, яким реально ходить поїзд. Якщо між станціями є кілька ліній, додайте проміжну станцію.
- Тайли OpenRailwayMap підходять для тестів; для продакшну потрібен свій тайл-сервер.
